# Quick Spec: Finish screen, pause menu and map select

**Category:** Small addition (UI over the existing run loop)
**Date:** 2026-11-04
**Requested by:** Conner, playtest feedback: "when you finish a run there's no way to restart or switch maps"
**Design record:** `design/game-brief.md` (Core loop: "see your time and splits against your best, and restart instantly"; Controls: "Restart: one button, any time")

## Change

1. **Finish screen.** About a second after crossing the finish, a results panel
   appears over the course: final time, personal best and the difference, a
   "NEW BEST" callout, and each split against the best split. Buttons:
   **Ride again**, **Choose map**, **Quit game**. `R` / gamepad Y still restarts
   instantly from anywhere.
2. **Pause menu.** `Esc` / `P` / gamepad Start pauses mid-run (the world stops,
   the clock stops). Buttons: **Resume**, **Restart run**, **Choose map**,
   **Quit game**. Pressing pause again resumes.
3. **Map select.** Lists every course in `assets/data/courses.json` with its
   blurb and saved best time. Picking one loads it from the top. **Back** (or
   `Esc`) returns to the previous panel.
4. **Saved bests.** Best time and best splits per course are saved on the
   player's PC (`user://records.cfg`) so they survive restarts, map switches and
   closing the game.

Menus work with mouse, keyboard (arrows + Enter/Space) and gamepad (D-pad +
A). The first button is focused when a panel opens.

## Tuning knobs (data, not code)

- `assets/data/courses.json`: course list (id, name, data path, blurb). A new
  course appears in map select by adding an entry.
- `assets/data/run_menu.json`: `finish_menu_delay_s` (default 1.2).

## Acceptance criteria

- [ ] Crossing the finish shows the results panel with time, best and splits.
- [ ] "Ride again" puts the skater at the top with the clock at 0:00.00.
- [ ] "Choose map" lists Copperline Mountain and Test Slope; picking one loads it.
- [ ] Esc pauses a run and stops the clock; Resume continues from the same spot.
- [ ] A best time set on a course is still shown after quitting and relaunching.
- [ ] Unit tests cover the records logic and course list parsing.

## Out of scope

Main title screen, settings/options, ghost replays, leaderboards.
